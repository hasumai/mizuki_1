# 数据分析成长面板

访问网站的 `/skills/` 页面，在顶部的“数据分析成长”区管理学习进度。原有前端、后端、数据库等技能展示保留在面板下方。

- 每项可选“未开始 / 学习中 / 已掌握”，也可编辑名称、完成标准和个人记录。
- 按分类筛选或搜索；新增的项目可以删除。
- 主线完成度不包含“拓展选学”，避免选修项目改变主线进度。
- 记录保存在当前浏览器的本地存储中。静态网站没有账户或跨设备自动同步；换浏览器、换设备或清除网站数据前，先点“导出”，之后用“导入”恢复。备份文件由本人保管。
- 预置学习路径位于 `src/data/analysis-learning.ts`。修改这份文件并重新部署会影响新用户的默认清单；已经在浏览器中编辑过的条目会保留其个人版本。

现有网站地址由 `src/config.ts` 的 `siteURL` 配置；代码推送至 GitHub 后，还需要网站托管平台完成部署，线上页面才会更新。
